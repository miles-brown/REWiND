# Keyboard Navigation & Shortcuts Guide

REWIND is engineered with keyboard-first navigation for historians, journalists, and researchers.

---

## 1. Global Timeline Hotkeys

These shortcuts operate anywhere on the timeline console ([`PersonTimeline.tsx`](file:///Users/milesbrown/Github/REWiND/components/rewind/PersonTimeline.tsx) and [`RewindExplorer.tsx`](file:///Users/milesbrown/Github/REWiND/components/rewind/RewindExplorer.tsx)):

| Keybinding | Action | Description |
| :--- | :--- | :--- |
| <kbd>→</kbd> | **Next Event** | Steps forward chronologically by 1 event. |
| <kbd>←</kbd> | **Previous Event** | Steps backward chronologically by 1 event. |
| <kbd>Shift</kbd> + <kbd>→</kbd> | **Jump +5 Events** | Fast-forwards by 5 events. |
| <kbd>Shift</kbd> + <kbd>←</kbd> | **Jump -5 Events** | Rewinds by 5 events. |
| <kbd>Space</kbd> | **Play / Pause** | Toggles automated interval playback. |
| <kbd>Home</kbd> | **Earliest Record** | Jumps instantly to the first documented event in the index. |
| <kbd>End</kbd> | **Latest Record** | Jumps instantly to the most recent event. |
| <kbd>R</kbd> | **Toggle Direction** | Switches playback direction between Forward and REWIND mode. |
| <kbd>?</kbd> | **Toggle Help** | Shows/hides the keyboard shortcuts reference bar. |

## 2. Global Search & Command Palette

| Keybinding | Action | Description |
| :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>K</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | **Open Palette** | Opens the global command search dialog from anywhere in the app. |
| <kbd>↓</kbd> / <kbd>↑</kbd> | **Navigate Results** | Moves selection highlight up and down. |
| <kbd>Enter</kbd> | **Select / Open** | Navigates immediately to the selected event, person, quote, place, or source. |
| <kbd>Esc</kbd> | **Dismiss** | Closes the modal and returns focus to the previous element. |
